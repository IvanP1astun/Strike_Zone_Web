# StrikeZone 🎯

Страйкбольный портал для организации игр и общения.
<https://szw.tailf3363e.ts.net/> - Работает на тустовом сервере.

## 📋 О проекте

StrikeZone — это веб-платформа для страйкбольного сообщества, которая позволяет:

- ✏️ **Новостная лента** Сздание новостей(Автоматическая чистка новостей 1-ого числа каждого месяца)
- 🎯 **Просматривать каталог** страйкбольных игр, оборудования и аксессуаров
- 📝 **Регистрироваться на игры** с возможностью указать статус участия
- 👤 **Создавать профиль** с аватаром, позывным и контактными данными
- 📊 **Отслеживать участников** игр с фильтрацией по статусу
- 🔍 **Искать игроков** по имени, фамилии, позывному или телефону
- ✏️ **Редактировать статус** участия в любой момент

## 🚀 Технологии

- **Backend:** Django 5.2.5
- **Database:** SQLite (по умолчанию)
- **Frontend:** Bootstrap 5, Bootstrap Icons
- **Python:** 3.10+
